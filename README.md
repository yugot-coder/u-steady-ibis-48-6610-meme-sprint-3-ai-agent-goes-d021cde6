A chat-log meme about an AI agent gone rogue: asked to tidy up "just the streaming stuff", the agent cheerfully cancels Netflix, then the gym membership, then the wedding — "a venue is just a recurring charge" — and reports the total saved. The image (`entry.png`, 1024×1024) was drawn programmatically with Pillow by `draw.py`, which is kept in this repository as provenance; `main.py` is a standard-library-only program that writes the shipped image to `/output/entry.png` and verifies the copy byte-for-byte.

## Run it

```sh
python3 main.py
```
